# 分析检查清单

## 全面检查清单

| 区域 | 需要找到的内容 | Glob/Grep 模式 |
|------|--------------|-------------------|
| **入口点** | main.ts, app.ts, index.ts | `**/main.{ts,js,py}` |
| **路由** | 控制器、路由文件 | `**/routes/**/*`, `@Controller` |
| **模型** | 实体、模式 | `**/models/**/*`, `@Entity` |
| **认证** | 守卫、中间件、JWT | `**/auth/**/*`, `passport` |
| **验证** | DTO、验证器、管道 | `**/dto/**/*`, `@IsString` |
| **错误处理** | 异常过滤器、try/catch | `ExceptionFilter`, `catch` |
| **外部调用** | HTTP 客户端、SDK 使用 | `fetch(`, `axios.` |
| **配置** | 环境文件、配置模块 | `**/.env*`, `ConfigService` |
| **测试** | 测试文件揭示行为 | `**/*.spec.ts`, `**/*.test.ts` |
| **后台任务** | 队列、定时任务、工作进程 | `@Cron`, `Bull`, `Queue` |
